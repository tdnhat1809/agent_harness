# UI/UX Stack: Impeccable Design Craft

Prevent generic AI templates and elevate web applications to world-class software craftsmanship.

## Anti-AI-Slop Rules

1. **No Generic Purple/Blue Gradients**:
   - Avoid generic AI aesthetic defaults (e.g. overused purple-indigo gradients on dark grey cards).
   - Use nuanced, tailored color palettes with distinct accent tokens, subtle luminous borders, and curated dark/light modes.

2. **No "Cards Inside Cards Inside Cards"**:
   - Use whitespace, subtle dividers, typography scales, and surface tonal shifts rather than stacking border boxes indefinitely.

3. **No Uncalibrated Typography**:
   - Never use browser default system fonts without styling.
   - Use modern font stacks (e.g., Inter, Plus Jakarta Sans, Outfit, Geist, JetBrains Mono for code).
   - Maintain strict optical hierarchy: tight tracking on large headers (`tracking-tight`), comfortable line heights on body prose (`leading-relaxed`).

4. **Intentional Micro-Interactions**:
   - Add purposeful hover, active, and focus states on all interactive elements.
   - Use smooth bezier curves (`cubic-bezier(0.16, 1, 0.3, 1)`) rather than bouncy or abrupt transitions.

5. **Lived-In Real Content (No Placeholders)**:
   - Provide realistic, rich data and functional media demos instead of placeholder text (`Lorem Ipsum` or blank rectangles).
