# Superpowers: Brainstorming & Intent Elicitation

Use this skill whenever a task is conceptually open-ended, architecturally significant, or when multiple valid approaches exist.

## Core Rules

1. **Never Assume Ambiguous Intent**:
   - Ask targeted questions to clarify scope, constraints, and non-functional requirements.
   - Formulate options with clear pros, cons, and engineering trade-offs.

2. **Divergent to Convergent Thinking**:
   - **Phase 1 (Diverge)**: Explore 2–3 distinct architectural or design approaches.
   - **Phase 2 (Evaluate)**: Assess feasibility, complexity, performance impact, and maintenance burden.
   - **Phase 3 (Converge)**: Agree on a single recommended approach with user confirmation.

3. **Output Format**:
   - Brief Summary of Problem Context
   - Approach Comparison Table (Complexity, Performance, DX, Risk)
   - Concrete Recommendation (with rationale)
   - Next Action Item: Transition into `writing-plans`.
